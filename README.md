# pruebas

## leads-app

App web para cargar y seguir los leads de la planilla "Fecundart - Seguimiento de Leads"
(Google Apps Script, vinculada a la planilla). Todo se configura desde la hoja **Config**.

- Instalación, uso y configuración: [leads-app/GUIA.md](leads-app/GUIA.md)
- Vista previa con datos de prueba: `leads-app/dev/vista-previa.html`
- Tests: `cd leads-app && npm test`
